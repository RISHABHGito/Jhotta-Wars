## 📖 About

**BLOCK BRAWL** is a retro-inspired 2D PvP (Player vs Player) fighting game that brings back the classic arcade fighting experience reminiscent of the legendary Tekken series. Engage in fast-paced, head-to-head combat with simple mechanics yet deep strategic gameplay.

### 🎯 Game Features

- **2-Player PvP Combat** — Battle against a friend on the same keyboard
- **Retro Pixel Art Style** — Classic 8-bit inspired graphics and aesthetics
- **Arcade Controls** — Simple and responsive input system for fluid gameplay
- **Dynamic Combat** — Master combos, blocks, and timing to defeat your opponent
- **Responsive Design** — Play on desktop with optimized controls

## 🕹️ How to Play

### Controls

#### Player 1 (Left Side)
- **Move Left:** `A` key
- **Move Right:** `D` key
- **Jump:** `W` key
- **Attack:** `Space` key
- **Block:** `S` key

#### Player 2 (Right Side)
- **Move Left:** `←` Arrow key
- **Move Right:** `→` Arrow key
- **Jump:** `↑` Arrow key
- **Attack:** `Enter` key
- **Block:** `↓` Arrow key

### Gameplay Tips

1. **Master the Basics** — Learn when to attack, block, and move
2. **Watch Your Opponent** — Predict their moves and counter-attack
3. **Manage Distance** — Keep optimal spacing for your fighting style
4. **Combo Timing** — Chain attacks together for higher damage
5. **Block Strategically** — Don't block continuously; time your blocks to avoid stamina drain

## 🛠️ Technical Details

### Technology Stack
- **Frontend:** Pure JavaScript (Vanilla JS)
- **Graphics:** HTML5 Canvas API
- **Styling:** CSS3
- **Font:** Press Start 2P (Google Fonts)

### File Structure
```
fighter-game/
├── index.html          # Main HTML file with canvas
├── css/
│   └── game.css       # Game styling and canvas setup
├── js/

│   ├── characters.js  # Character classes and mechanics
│   └── input.js       # Input handling and controls
```

## 🚀 Getting Started

### Play Online
Simply click the **[▶️ PLAY NOW](https://rishabhgito.github.io/Jhotta-Wars/fighter-game/)** button at the top!

### Run Locally

1. **Clone the Repository**
   ```bash
   git clone https://github.com/RISHABHGito/Jhotta-Wars.git
   cd Jhotta-Wars/fighter-game
   ```

2. **Open in Browser**
   - Double-click `index.html`, or
   - Use a local server:
     ```bash
     python -m http.server 8000
     # Then visit: http://localhost:8000/fighter-game/
     ```
